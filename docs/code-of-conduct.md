# Code of Conduct

Mewa Code is committed to a welcoming, respectful, and harassment-free community for everyone.

## Expected behavior

Be considerate, constructive, and respectful. Assume good intent, welcome different perspectives, and focus
feedback on the work rather than the person.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized language or imagery, doxxing, and
deliberate disruption are not welcome in project spaces.

## Reporting

Report a concern privately to the project maintainers through the repository's security or contact channel.
Do not include sensitive details in a public issue.
