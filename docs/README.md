# Documentation

These documents define the active Mewa Code product and implementation boundaries.

- [`product-baseline.md`](product-baseline.md) — authoritative product goals, retained capabilities, and non-goals.
- [`architecture.md`](architecture.md) — runtime components and ownership boundaries.
- [`model-management.md`](model-management.md) — provider/model ownership, catalog metadata, authentication, cost display, and visibility semantics.
- [`implementation-plan.md`](implementation-plan.md) — ordered delivery plan for coding agents.
- [`current-state.md`](current-state.md) — what the rewrite branch currently provides and what remains to remove or adapt.
- [`security.md`](security.md) — trust model, credentials, SSH authority, browser isolation, and exposure rules.

Older ThinkRail and pre-rewrite Mewa behavior is historical context only. When code and documentation disagree, the product baseline wins and the implementation should be reduced or adapted accordingly.
