# Documentation

- [`product-baseline.md`](product-baseline.md) is the canonical product scope and acceptance baseline.
- [`foundation-inventory.md`](foundation-inventory.md) records current inherited coupling without granting scope.
- [`contributing.md`](contributing.md) describes contribution practices.
- [`code-of-conduct.md`](code-of-conduct.md) contains the community conduct policy.
- [`foundation/`](foundation/) contains selected reference material retained from the imported UI.

Product, architecture, security, deployment, and engineering documentation belongs in this directory. Root `README.md`, `AGENTS.md`, `CLAUDE.md`, `NOTICE.md`, and `LICENSE` remain at repository root because tooling or legal conventions require them. Markdown under runtime `skills/` directories is executable prompt content rather than project documentation.
